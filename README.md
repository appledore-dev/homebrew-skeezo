# Skeezo Homebrew tap

Install [Skeezo](https://skeezo.dev/) — an agent-native macOS IDE that drives your
already-installed Claude Code CLI.

```sh
brew install --cask appledore-dev/skeezo/skeezo
```

Skeezo updates itself in-app, so the cask is marked `auto_updates true`. To move
the installed copy to the latest release through Homebrew instead:

```sh
brew update && brew upgrade --cask skeezo
```

Requires Apple silicon and macOS 11 (Big Sur) or newer. Skeezo is proprietary
software; this tap only carries the installer. `Casks/skeezo.rb` is generated by
the release build — edit it there, not here.
